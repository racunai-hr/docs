# ISO/IEC 27001 certifikat — obaveza i status

## Zahtjev zakona (čl. 61. st. 1. t. 2. ZOF)

Informacijski posrednik mora Poreznoj upravi dostaviti **najnoviju verziju certifikata ISO/IEC 27001** u trenutku podnošenja dokumentacije.

To **nije** izjava ni plan — mora biti certifikat izdan od **akreditiranog certificirajućeg tijela** za sustav upravljanja informacijskom sigurnošću (ISMS).

## Trenutni status Fine Star d.o.o.

| Stavka | Status |
|--------|--------|
| ISO 27001 certifikat | **Nije izdan** |
| ISMS dokumentacija | U pripremi (track 0.15) |
| Gap analiza / certificiranje | Nije započeto (track 0.14) |

## Što uploadati na PTS (polje „ISO certifikat“)

Kad certifikat bude izdan, uploadati **PDF certifikata** koji sadrži:

- naziv certificiranog subjekta (Fine Star d.o.o. ili grupa koja pokriva racunAI ISMS)
- broj certifikata
- datum izdavanja i rok valjanosti
- certificirajuće tijelo (npr. DEKRA, Bureau Veritas, SGS, …)
- opseg certifikacije (scope statement)

## Preporučeni sljedeći koraci

1. Gap analiza prema ISO 27001:2022 (3 ponude — track 0.14)
2. Implementacija ISMS-a (politike, procjena rizika, SOA)
3. Internal audit + certificiranje Stage 1 / Stage 2
4. Upload certifikata na PTS

## Alternativa za brže testiranje infrastrukture

Ako je cilj **samo proći tehničke PTS testove** (AS4, MPS, fiskalizacija) za **vlastitu pristupnu točku**:

- PTS svrha: **„Za sebe“** (čl. 63.) — **bez** obveze dokumentacije iz čl. 61.
- Informacijski posrednik (Faza 2) zahtijeva ISO + ove dokumente + završni popis PU.
