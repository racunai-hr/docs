# Prilagođena domena (custom domain) — onboarding

Ovaj vodič opisuje kako povezati vlastitu domenu klijenta s tenantom u RačunAI ERP-u.

## Preduvjeti

- Tenant je kreiran u Django adminu (`admin.racunai.hr`) s aktivnim slugom (npr. `finestar`).
- Klijent kontrolira DNS zonu svoje domene (npr. `nekafirma.hr`).
- Traefik na serveru ima pristup `/opt/stacks/traefik/dynamic/` (file provider s `watch=true`).

## Koraci

### 1. DNS kod klijenta

Postavite **CNAME** (preporučeno) ili **A** zapis:

| Tip   | Ime              | Vrijednost                          |
|-------|------------------|-------------------------------------|
| CNAME | `erp.nekafirma.hr` | `finestar.racunai.hr` (ili Traefik IP) |
| A     | `erp.nekafirma.hr` | IP adresa Traefik servera           |

Ako je domena na Cloudflare-u, uključite proxy (narančasti oblak) samo ako koristite `certResolver: cloudflare`.

### 2. Postavite custom domenu u adminu

1. Prijavite se na `https://admin.racunai.hr/admin/`
2. Otvorite **Tenanti → [tenant]**
3. U polje **Prilagođena domena** unesite točan host bez sheme: `erp.nekafirma.hr`
4. Spremite

Pri spremanju ERP automatski:

- ažurira Django `ALLOWED_HOSTS` / `CSRF_TRUSTED_ORIGINS` preko `DynamicAllowedHostsMiddleware`
- generira Traefik router u `/opt/stacks/traefik/dynamic/racunai-erp-custom.yml`

Ručna regeneracija (npr. nakon deploya):

```bash
cd /opt/stacks/finestar/erp
docker compose exec web python manage.py sync_custom_domain_routers
```

### 3. Provjera Traefik routera

Primjer generirane datoteke (`racunai-erp-custom.yml`):

```yaml
# Auto-generated by racunai ERP — sync_custom_domain_routers
http:
  routers:
    racunai-erp-custom-finestar:
      rule: Host(`erp.nekafirma.hr`)
      entryPoints:
        - websecure
      service: racunai-erp@docker
      priority: 90
      tls:
        certResolver: cloudflare
```

Traefik učitava promjene automatski (file watch). Provjera:

```bash
curl -sI https://erp.nekafirma.hr/admin/ | head -5
docker logs traefik --since=10m 2>&1 | rg -i 'erp.nekafirma|acme|certificate'
```

### 4. TLS strategija

| Scenarij | `TENANT_CUSTOM_DOMAIN_CERT_RESOLVER` | Napomena |
|----------|----------------------------------------|----------|
| Domena na Cloudflare DNS | `cloudflare` (default) | DNS-01 preko globalnog CF tokena u Traefiku |
| Domena izvan CF, CNAME na server | `lehttp` | HTTP-01 na portu 80 |

Postavite u `.env`:

```
TENANT_CUSTOM_DOMAIN_CERT_RESOLVER=cloudflare
TENANT_TRAEFIK_DYNAMIC_PATH=/opt/stacks/traefik/dynamic/racunai-erp-custom.yml
```

### 5. Smoke test

```bash
# Tenant resolution + TLS
curl -sI https://erp.nekafirma.hr/admin/ | head -3

# Django ALLOWED_HOSTS (ne smije vratiti 400 DisallowedHost)
curl -sI -H "Host: erp.nekafirma.hr" https://<server-ip>/admin/ 2>/dev/null | head -3
```

U adminu provjerite da se podaci filtriraju ispravno za tenant povezan s custom domenom.

## Uklanjanje custom domene

1. Očistite polje **Prilagođena domena** u adminu i spremite
2. Uklonite DNS zapis kod klijenta
3. Router se automatski uklanja iz `racunai-erp-custom.yml`

## Troubleshooting

| Simptom | Uzrok | Rješenje |
|---------|-------|----------|
| `DisallowedHost` | Host nije u cacheu | Spremite tenant ponovo ili `sync_custom_domain_routers` |
| 404 Traefik | Nema routera | Provjerite YAML u `/opt/stacks/traefik/dynamic/` |
| 404 Django | Tenant nije pronađen | Provjerite `custom_domain` točno odgovara Host headeru |
| CSRF greška na login | Origin nije trusted | Middleware dodaje `https://{host}` automatski |
| Cert pending | ACME/DNS | Provjerite CF token ili DNS propagaciju |

## Arhitektura

```
Klijent DNS (erp.nekafirma.hr)
    → Traefik dynamic router (priority 90)
    → racunai-erp@docker :8000
    → DynamicAllowedHostsMiddleware
    → TenantMiddleware (custom_domain lookup)
    → Django admin / aplikacija
```

Platformski hostovi (`admin.racunai.hr`, `{slug}.racunai.hr`, `erp.finestar.hr`) koriste statičke routere u `docker-compose.yml` i ne ovise o ovom flowu.
